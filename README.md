# Kroo's Recycle Items

An SKSE plugin for Skyrim Special Edition (Anniversary Edition runtime) that lets you recycle the gear you no
longer use at the smelter, the tanning rack and the staff enchanter, and get crafting materials back.

- A **RECYCLING** section in the crafting menu, sorted into Weapons, Armor, Jewelry, Clothing and Miscellaneous items.
- Yields come from each item's own crafting recipe, including recipes added by other mods, and rise with Smithing.
- A confirmation box shows what you will get and your chances; a second box shows what you recovered.
- MCM (MCM Helper) and a FOMOD installer, in English and French.

## Requirements

- Skyrim Special Edition, Anniversary Edition runtime (1.6 or later; tested on 1.7.104). Not for 1.5.97 or VR.
- [SKSE64](https://skse.silverlock.org/)
- [Address Library for SKSE Plugins](https://www.nexusmods.com/skyrimspecialedition/mods/32444)
- [Constructible Object Custom Keyword System](https://www.nexusmods.com/skyrimspecialedition/mods/81409)
- [SkyUI](https://www.nexusmods.com/skyrimspecialedition/mods/12604)
- [MCM Helper](https://www.nexusmods.com/skyrimspecialedition/mods/53000)

## Building

You need Windows, Visual Studio 2022 with the MSVC v143 toolset, [vcpkg](https://github.com/microsoft/vcpkg),
the [CommonLibSSE-NG](https://github.com/alandtse/CommonLibSSE-NG) 9.1.0 source tree and Python 3.

1. Copy `tools/local-paths.example.ps1` to `tools/local-paths.ps1` and set the paths.
2. Build the DLL from PowerShell: `tools\build.ps1 -NoDeploy` (without `-NoDeploy`, it also copies the DLL
   and `data/` to the MO2 folder set in `local-paths.ps1`).
3. Build the release archive with its FOMOD installer: `python tools/make-fomod.py` (needs Pillow).
   It writes `build/KroosRecycleItems-<version>.zip`.

The files in `data/` are generated by scripts, edit those instead:

| File | Script |
|---|---|
| `KroosRecycleItems.esl` | `tools/make-esl.py` |
| `Interface/Translations/*.txt` | `tools/make-translations.py` |
| `Interface/kroosrecycleitems/icons.swf` | `tools/make-icon.py` (needs OpenCV and Pillow) |

## Layout

- `src/RecipeScan.cpp`: reads every recipe when the game starts and decides what each item gives back, and where.
- `src/RecycleMenu.cpp`: the RECYCLING section in the crafting menu.
- `src/Recycler.cpp`: yields, chances, level requirements, confirmation and the recycling itself.
- `src/Settings.cpp`, `src/Text.cpp`: MCM settings and translated texts.
- `data/`: plugin, MCM, CraftingCategories config, miscellaneous item rules, translations, icon.
